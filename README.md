# Quizo - Online Quiz Platform 🎓🖥️

منصة اختبارات إلكترونية متكاملة مبنية باستخدام إطار العمل **Laravel** وتقنية **Inertia.js** مع **React**.

## المميزات
- **نظام إدارة الأسئلة (Admin Dashboard)**: لوحة تحكم كاملة للمسؤول لإضافة، تعديل، وحذف الأسئلة.
- **تجربة مستخدم حديثة**: واجهة اختبار تفاعلية، سريعة، ومتجاوبة مع كافة الشاشات.
- **قاعدة بيانات متطورة**: استخدام PostgreSQL (عبر Supabase) لإدارة البيانات بكفاءة.
- **تصميم عصري**: اعتماد النمط الفاتح (Light Mode) مع هوية بصرية مخصصة.
- **حماية عالية**: نظام توثيق (Authentication) متكامل للمسؤولين.

## التقنيات المستخدمة
- **Backend**: Laravel 12
- **Frontend**: React 18 & Tailwind CSS
- **Bridge**: Inertia.js
- **Database**: PostgreSQL
- **Deployment**: Docker & Render

## كيفية التشغيل محلياً
1. قم بتحميل المشروع (Clone):
   ```bash
   git clone https://github.com/zakariasersoub/quiz-platform.git
   ```
2. قم بتثبيت الملحقات:
   ```bash
   composer install
   npm install
   ```
3. قم بإعداد ملف `.env` وتهيئة قاعدة البيانات.
4. شغّل المشروع:
   ```bash
   php artisan serve
   npm run dev
   ```
